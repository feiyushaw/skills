# Productivity Skills

- `grill-me`: explicit user entry to the reusable `core/grilling` discipline.
- `teach`: persistent learning workspace.
- `to-questionnaire`: turn external knowledge gaps into answerable questionnaires.
- `wait-what`: re-pitch the previous explanation with missing context.

Cross-domain `handoff` remains under `core` because it is shared by engineering, research, presentations, and patents.
