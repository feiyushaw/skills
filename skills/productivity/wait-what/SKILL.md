# Wait, What?

Re-explain the immediately preceding material.

- Add the missing context before details.
- Use plain, standard technical English or the user's current language.
- Prefer the ubiquitous vocabulary in `CONTEXT.md` when present.
- Expand acronyms or assumptions that were introduced too abruptly.
- Preserve the technical conclusion; improve comprehension rather than changing the decision.
- Use a concrete example only when it materially clarifies the concept.

The result should let the user reconnect the current point to the larger task without rereading the whole conversation.
