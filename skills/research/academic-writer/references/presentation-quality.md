# Figure, Table, and Presentation Quality

## Purpose

Use this reference during manuscript drafting and revision to ensure that figures, tables, captions, and layout communicate evidence cleanly.

## One visual, one message

For each figure or table, complete:

```text
After seeing this artifact, the reader should understand / believe / evaluate that ______.
```

If the message is unclear, redesign the artifact or move it to supplementary material.

## Figure captions

A caption should let the reader understand the setting, visual encoding, and main comparison without reconstructing missing context from the body text.

Prefer:

- what is shown;
- key conditions/settings;
- definitions of panels/symbols if needed;
- what uncertainty/error bars represent;
- concise statement of the intended comparison.

Do not turn the caption into a duplicate Discussion section.

## Table design

Prefer publication-style tables:

- caption above table unless venue rules differ;
- use `booktabs`-style rules rather than dense grids;
- avoid vertical rules where possible;
- label metric direction explicitly, e.g. `Accuracy ↑`, `Error ↓`;
- include units when needed;
- use consistent numeric precision within a metric;
- align numeric values consistently;
- group multi-setting results with structural headers rather than visual clutter;
- use restrained emphasis for key values;
- make each table answer one main question.

## Highlighting

Highlighting should guide attention, not pre-interpret every cell. Avoid excessive bolding, colors, or decorations. When showing best/second-best values, follow venue conventions and keep the rule consistent.

## Visual hierarchy

A reader should be able to identify quickly:

1. what is being compared;
2. what varies;
3. what metric matters;
4. what uncertainty exists;
5. what conclusion is safe to draw.

## Placement and reading flow

Place a figure/table close to its first substantive discussion. Do not introduce an important visual many pages before or after its explanation.

For two-column formats, consider page reading flow and avoid placements that unnecessarily interrupt the main narrative, while always obeying venue formatting constraints.

## Consistency audit

Across the manuscript, check:

- same terminology in text and visuals;
- same method names and abbreviations;
- same metric direction/units;
- same decimal precision policy;
- consistent panel labels;
- consistent legend ordering when comparing the same methods;
- captions do not contradict the main text.
