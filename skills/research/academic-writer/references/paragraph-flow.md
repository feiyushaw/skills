# Paragraph Flow and Reverse-Outline Guidance

## Purpose

Use this reference when drafting or revising paragraph-level academic prose.

## One paragraph, one scientific job

Each paragraph should have one dominant message. A useful contract is:

```text
paragraph role
→ topic sentence
→ supporting reasoning / evidence
→ qualification if needed
→ transition
```

The first sentence should usually make the paragraph's role legible to an external reader. Do not make the reader infer the paragraph's purpose from its final sentence.

## Sentence-to-sentence relations

Each new sentence should have an identifiable relation to the previous one, such as:

- cause;
- contrast;
- consequence;
- refinement;
- definition;
- evidence;
- example;
- limitation.

If two adjacent sentences have no clear relation, either add the missing logical bridge, reorder them, or split the paragraph.

## Self-contained terminology

- Define a technical term before using it as shared context.
- Keep key nouns stable across the paper.
- Avoid switching between near-synonyms for the same technical object unless the distinction is intentional.
- Prefer explicit subjects over vague references such as `this`, `it`, or `they` when ambiguity is possible.

## Reverse outline

After drafting a section, create a compact reverse outline:

```text
Section thesis:

P1 topic sentence:
  support/evidence:

P2 topic sentence:
  support/evidence:

P3 topic sentence:
  support/evidence:
```

Audit two mappings:

```text
paragraph topic → section thesis
support/evidence → paragraph topic
```

A paragraph that cannot be mapped cleanly is a candidate for deletion, relocation, or rewriting.

## Flow audit

Ask:

1. Does every paragraph have one clear message?
2. Does the opening sentence expose that message?
3. Does every sentence have a clear relation to the previous sentence?
4. Are technical nouns and terms stable?
5. Does each paragraph advance the section thesis rather than merely add background?
6. Does the final sentence naturally prepare the next paragraph or subsection?

## Temporary scaffolding

When a section feels difficult to follow, temporarily add explicit labels such as `Motivation`, `Challenge`, `Design`, `Evidence`, or `Limitation`. Rebuild the flow under these labels, then remove unnecessary scaffolding in the final manuscript.
