# Novelty Ladder

Use this ladder as a diagnostic, not as an absolute publication score.

| Level | Pattern | Typical interpretation |
|---|---|---|
| L0 | Use A for B | application / transfer |
| L1 | Adapt A for B | engineering adaptation |
| L2 | Modify mechanism A to resolve limitation X | method innovation |
| L3 | Identify a previously overlooked mechanism/problem | conceptual innovation |
| L4 | Establish a new formulation/framework that reorganizes the problem | framework innovation |
| L5 | Establish a new principle/theory/paradigm | fundamental contribution |

## Rules

1. Higher is not automatically better; significance and evidence still matter.
2. Do not upgrade a level using writing alone. The underlying research object must change.
3. If the novelty collapses under standard terminology, lower the classification.
4. If the contribution is primarily implementation quality, say so explicitly.

## Upgrade questions

To move from L0/L1 toward L2:

- What specific limitation makes direct transfer insufficient?
- What mechanism must change?
- Can the modification be isolated experimentally?

To move toward L3:

- What previously unrecognized failure mode, dependency, or mechanism has been identified?
- Does this insight explain observations that prior approaches do not?

To move toward L4:

- Does the new formulation change the optimization target, information structure, decomposition, or problem definition?
- Does it subsume or reinterpret existing methods?

To move toward L5:

- Is there a general principle/theory beyond the specific implementation?
- Can it generate new predictions or guarantees?
