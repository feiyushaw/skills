# Engineering Skills

Primary flow:

```text
grilling / domain-modeling
→ to-spec
→ to-tickets
→ implement
   ├─ prototype
   ├─ tdd
   └─ diagnosing-bugs
→ code-review
```

Use `codebase-design` when interface/seam/module shape is the question. Use `wayfinder` before `to-spec` when the route itself spans multiple sessions and still contains unresolved decisions. Use `resolving-merge-conflicts` only for an active Git merge/rebase conflict.
