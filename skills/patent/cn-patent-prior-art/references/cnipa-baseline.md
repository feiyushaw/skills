# CNIPA baseline for software / AI invention drafting

Working baseline only; verify the currently effective law, regulations, Patent Examination Guidelines, and official CNIPA notices before filing.

Software/AI inventions should be framed as technical solutions considering algorithm/software and technical features as a whole, with sufficient disclosure and a concrete technical effect. AI construction/training inventions need material model/training details; domain applications should define technical input/output relationships. Routine scene substitution without technical adaptation is weak inventive-step support.

Verify current Patent Law, Implementing Regulations, effective Patent Examination Guidelines, CNIPA AI guidance, and current official interpretations before filing-quality conclusions.
